# CodingAgents 07 — Bounded Subagents & Synthesis

Companion deck for **Component 6** of Sebastian Raschka's *[Components of a Coding Agent](https://magazine.sebastianraschka.com/p/components-of-a-coding-agent)*, plus a closing synthesis tying all six components together. Covers the spawn-vs-bind distinction, what context flows across the parent/child boundary, sandboxing and recursion-depth bounds, the architectural difference between Claude Code and Codex CLI subagent models, and a catalogue of five concrete subagent patterns (research, parallel-edit, review, autonomous slice, planner/executor).

Includes an interactive subagent-tree visualiser that walks each pattern, plus a reading list pointing to production harness sources, related Anthropic engineering essays, and the rest of this hub.
